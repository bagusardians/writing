Word counts are computed on the same basis as v1.1.0 only where noted; v1.1.0's 50,326
included the assembled total on the original assembly method. From v1.2.0 onward the figure
is words excluding image prompts, the same basis used to measure v1.1.0 at 44,951. v1.2.0
(46,666) is the continuity revision. v1.3.0 (44,955) is the page-turner pass, which cut
roughly as much prose as it added.

Working drafts and the editable chapter files live in `../phase-6-draft/`. A release is a
frozen copy assembled from those chapters; it is not edited in place. To revise, produce a
new version folder rather than editing a release.

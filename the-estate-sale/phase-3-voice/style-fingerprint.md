# The Estate Sale — Style Fingerprint (Phase 3)

Feature-only profile of the target voice: the documentary interiority of Uketsu's "Strange"
series and the macabre-fair-play tradition. No source text is reproduced or stored.

## Provenance

- **Target features:** Uketsu (conversational documentary frame; images as clues; mundane
  surface yielding retroactive horror; interlocking cases).
- **Study set:** public summaries, reviews, and structural descriptions of *Strange
  Pictures*, *Strange Houses*, *Strange Buildings*, and *Strange Maps*; general mystery
  craft. No passages copied.
- **Date built:** 2026-10-03.

## Features

| Feature | Observation | Rule to apply |
|---|---|---|
| Sentence length and variance | Mostly short; long only when listing | Average 12–16 words; one inventory sentence per scene maximum |
| Punctuation habits | Dashes for interruption; few semicolons | Dashes yes, semicolons rare, no ellipses for suspense |
| POV and tense | Documentary first person; interleaved timelines | First past for frame; first present for live deaths; third past for cases |
| Scene versus summary | Almost all scene | Summarize only elapsed time between episodes |
| Dialogue versus narration | Heavy dialogue in investigation | Let evidence be questioned aloud, never lectured |
| Chapter length | Uniform, short | 1,500–3,000 words per episode |
| Imagery density | Low, concrete, functional | One anchor per scene; trade metaphors only |
| Structural devices | Standalone cases interlocking; a final chronological unlock | Reproduce exactly: 10 episodes + frame + unlock |

## Do and do not

- **Do** embed the clue in a plausible document before the character notices it.
- **Do** let the reader outrun the narrator.
- **Do** resolve each case with a physical cause.
- **Do not** copy any passage, character name, or plot from the source.
- **Do not** use the supernatural as a shortcut.
- **Do not** present this book as Uketsu's work.

## Sample paragraph spec

A live-POV paragraph should read as a person narrating inside a dying moment: present
tense, first person, ordinary nouns, restraint. The horror is in the narrator continuing to
do a normal thing — pose, unlock, pour tea — after the reader knows what it costs.

## Ethics note

- Only stylistic features are captured.
- No copyrighted passages are stored or reproduced.
- The output is original prose in a similar register, not the author's work.
